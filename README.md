# GambooBET Demo

投票画面のUI検討用デモです。

## 公開

GitHub Pagesの公開元を `main` ブランチのルートに設定してください。公開URLのルートから `vote/` へ移動します。

## 主なページ

- `vote/`：出走表
- `vote/prediction/`：予想
- `vote/odds/`：オッズ
- `vote/bet/`：投票入力
- `vote/bet/confirm/`：投票確認
- `vote/introduction/`：照会
- `vote/results/`：結果
- `vote/recent10/`：近10走詳細
- `vote/matchups/`：対戦成績
- `vote/comments/`：コメント

ボトムナビは使用していません。
